# Inscreva-se 🚀

Plataforma moderna para criação de formulários de inscrição personalizados e gestão de eventos.

## 🌐 Link do Projeto
Acesse a versão live aqui: **[https://inscreva-se.com](https://inscreva-se.com)**

---

## ✨ Funcionalidades
- **Criação de Eventos personalizada:** Escolha cores, temas (Luxo ou Minimalista) e fontes.
- **Formulários Dinâmicos:** Adicione campos conforme a necessidade do seu evento.
- **Gestão de Pagamentos:** Suporte para M-Pesa, E-Mola e transferência bancária com verificação de comprovativo.
- **Integração com WhatsApp:** Redirecionamento automático para grupos ou conversa direta com o mentor.
- **Painel de Controle:** Estatísticas de visitas e gestão completa de inscritos.

## 🛠️ Tecnologias
- **Frontend:** Next.js, Tailwind CSS, Framer Motion.
- **Backend:** Node.js, Express, MongoDB.
- **Storage:** Cloudinary (Imagens e Documentos).

---

## 🚀 Como rodar localmente

### 1. Clone o repositório
```bash
git clone https://github.com/afonsoDomingos/inscrevase.git
```

### 2. Configure o Backend
- Vá para a pasta `server`
- Crie um arquivo `.env` baseado no exemplo
- Instale as dependências: `npm install`
- Rode: `npm run dev`

### 3. Configure o Frontend
- Vá para a pasta `client`
- Instale as dependências: `npm install`
- Rode: `npm run dev`
